## Setup Guide

## 1. Obtain the Source Code

Clone the source code from the project distribution.

```
git clone https://github.com/Roml04/document-control-system.git
```

Then, navigate inside the project folder.

```
cd document-control-system
```

## 2. Configure the Environment Variables

### Configuring Environment Variables for Laravel

Create a copy of `backend/.env.docker.example` on the same directory and rename it to `.env.docker`.

Inside the `.env.docker` file, set the following variables.

| Variable            | Meaning                                                    |
| ------------------- | ---------------------------------------------------------- |
| `MAIL_FROM_ADDRESS` | A custom email address the mail notification is sent from. |

> Enclose the value in double quotation marks (`""`) to ensure values containing special characters are interpreted correctly.

| Variable         | Meaning                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `RESEND_API_KEY` | The API key generated by Resend, used to authenticate and authorize the application to send emails through the Resend API. |

> API keys are secret tokens used to authenticate your requests. They are unique to your account and must be kept confidential.

To create an API key, refer to [Resend's API Key Creation Guide](https://resend.com/docs/create-an-api-key).

| Variable  | Meaning                                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------------------- |
| `APP_KEY` | The Laravel application key used for encrypting data, securing sessions, and other encryption-related operations. |

This will be generated later on the application setup process. Leave this empty for now.

### Configuring Environment Variables for Docker Compose

Create a copy of `.env.example` on the same directory and rename it to `.env`

Inside the `.env` file, set the following variables with your preferred values.

| Variable              | Meaning                                            |
| --------------------- | -------------------------------------------------- |
| `MSYQL_USER`          | MySQL application user account username.           |
| `MYSQL_PASSWORD`      | Password for the MySQL application user account.   |
| `MYSQL_ROOT_PASSWORD` | Password for the MySQL root administrator account. |

| Variable                | Meaning                                                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ONLYOFFICE_JWT_SECRET` | The secret key used to sign and verify JSON Web Tokens (JWT) for authenticating requests between the application and ONLYOFFICE Document Server. |

This will be generated on the next step of the application setup process. Leave this empty for now.

### Start the Containers

To start the containers, run the command below on the root directory of the project.

```
docker compose up -d
```

Wait until all the containers are started.

To check whether all containers are up, run the command below on the root directory of the project.

```
docker compose ps
```

This will show all running containers.

It should display the following container names.

`document-control-system-backend`
`document-control-system-frontend`
`document-control-system-mysql`
`document-control-system-onlyoffice`
`document-control-system-worker`

Upon confirming that all containers are running, run the command below.

```
docker compose exec backend php -r "echo base64_encode(random_bytes(64)), PHP_EOL;"
```

This will return a 64 cryptographically secure random bytes which can be used on the `ONLYOFFICE_JWT_SECRET` variable.

Then, run the following command to generate a key for the `APP_KEY` variable on `backend/.env.docker` file.

```
docker compose exec backend php artisan key:generate --show
```

This will return an app key generated by Laravel itself.

Run the command below to apply the changes on the environment variables.

```
docker compose up -d --force-recreate
```

## 3. Initialize the Database

Run the following command to initialize the database schema.

```
docker compose exec backend php artisan migrate
```

Once these steps are complete, the application should be fully configured and ready to use.

The system can be accessed through the local IP address on port `3000` of the machine the project is hosted on.

> e.g. `192.168.254.2:3000`
